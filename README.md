# Sri Balaji Nivas – Real Estate Website

## Project Overview
A responsive real estate business website developed to showcase residential properties, apartment details and project information.

## Features
- Responsive homepage
- About Us section
- 2 BHK and 3 BHK apartment showcases
- Luxury penthouse showcase
- Property gallery
- Contact enquiry form
- WhatsApp integration
- Google Maps integration
- Downloadable property brochure

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

- index.html
- css/
- js/
- images/
- brochure.pdf
